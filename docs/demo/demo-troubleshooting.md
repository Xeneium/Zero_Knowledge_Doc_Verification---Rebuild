## 1. Port 8080 Conflict

### Symptom:
Application fails to start with:
```
Web server failed to start. Port 8080 was already in use.
```

### Diagnosis & Fix:

**On Windows (PowerShell):**
```powershell
# Find process holding port 8080
Get-NetTCPConnection -LocalPort 8080 -ErrorAction SilentlyContinue | Select-Object OwningProcess

# Forcefully kill the process (replace <PID> with the ID found above)
Stop-Process -Id <PID> -Force
```

**On Linux / macOS (Bash):**
```bash
# Find and terminate process on port 8080
lsof -ti :8080 | xargs kill -9
```

**Alternative:** Change server port on startup:
```bash
./mvnw spring-boot:run -pl zkdoc-api -Dspring-boot.run.arguments="--server.port=8081 --zkdoc.demo.seed-enabled=true"
```

## 2. Token Authentication & Expiry Errors

### Symptom:
`Failed to establish session: Token rejected by security validation` or HTTP 401 Unauthorized.

### Causes & Fixes:
1. **Audience or Issuer Mismatch:**
   - ZKDoc requires `iss: "https://auth.zkdoc.internal"` and `aud: "zkdoc-api"`.
   - Ensure you are using tokens generated by [`DemoTokenService`](file:///c:/Sabareesh/Easwari%20College/Semester%203/OOPs%20with%20Java/Project/Start%20over/Zero%20Knowledge%20Document%20Verification/zkdoc-api/src/main/java/com/zkdoc/api/demo/DemoTokenService.java) or via the **Demo Quick Connect** selector on `/login`.
2. **Demo Seeding Disabled:**
   - If `zkdoc.demo.seed-enabled` is false, demo keys are not in the trust registry.
   - Start the platform with:
     ```bash
     --zkdoc.demo.seed-enabled=true
     ```
3. **Fetching Fresh Tokens:**
   Run the CLI utility to fetch active tokens directly from the running server:
   ```powershell
   .\scripts\generate-demo-tokens.ps1
   ```

## 3. Camera Access & QR Code Scanning Issues

### Symptom:
The QR code scanner displays a black screen or errors with:
```
Could not start video source / NotAllowedError: Permission denied
```

### Causes & Fixes:
1. **Browser Permissions:**
   - In Chrome: Click the **tune/lock icon** next to `http://localhost:8080` in the URL bar $\rightarrow$ toggle **Camera** to **Allow** $\rightarrow$ refresh page.
2. **Insecure Context (Non-Localhost):**
   - WebRTC / Camera access requires a secure context (`https://` or `http://localhost`). If accessing via external IP (e.g. `http://192.168.x.x`), browsers block camera access by default.
3. **Fallback: File Upload & Manual Input:**
   - If camera access is unavailable, click the **"Upload Image"** tab to drag-and-drop a QR image file, or switch to the **"Manual Reference"** tab and paste the capability token `tok_demo_alice_degree_cred`.

## 4. Rate Limiting (HTTP 429 Too Many Requests)

### Symptom:
API responds with:
```json
{
  "status": 429,
  "error": "Too Many Requests",
  "message": "Rate limit exceeded. Please retry after some time."
}
```

### Diagnosis & Fix:
- ZKDoc protects sensitive verification and cryptographic endpoints using **Bucket4j**.
- If conducting automated testing or rapid clicking during a rehearsal:
  - Check the `Retry-After` response header (typically 1 to 5 seconds).
  - To increase or disable rate limiting for demonstration stress tests, edit [`zkdoc-api/src/main/resources/application.yml`](file:///c:/Sabareesh/Easwari%20College/Semester%203/OOPs%20with%20Java/Project/Start%20over/Zero%20Knowledge%20Document%20Verification/zkdoc-api/src/main/resources/application.yml):
    ```yaml
    zkdoc:
      rate-limit:
        enabled: false # Temporarily disable for heavy automated testing
    ```

## 5. Database Locks & Resetting Demo State

### Symptom:
- Database table lock errors in SQLite.
- Need to reset all credentials and audit logs back to the clean initial demo seed.

### Resolution (Clean Reset):
1. Stop the application (`Ctrl + C`).
2. Delete the temporary database and artifact directory:
   ```powershell
   Remove-Item -Recurse -Force ./data/db, ./data/artifacts
   ```
3. Re-run `.\scripts\demo-setup.ps1`. The application will re-apply Flyway migrations from clean state and seed the demo data afresh.

## 6. Missing or Corrupted PDF Test Fixtures

### Symptom:
`demo-degree-diploma.pdf` not found when attempting to demonstrate Mode A upload verification.

### Resolution:
Regenerate all synthetic PDF fixtures with the included zero-dependency Python script:
```bash
python demo/fixtures/generate_pdfs.py
```
This re-creates:
- `demo/fixtures/demo-degree-diploma.pdf` (Valid)
- `demo/fixtures/demo-degree-diploma-tampered.pdf` (Tampered honors/GPA)
- `demo/fixtures/demo-training-certificate.pdf` (Training certificate)
